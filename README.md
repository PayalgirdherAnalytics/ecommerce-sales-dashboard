📊 E-commerce Sales Dashboard (Excel Project)

📌 Project Overview:

This project focuses on performing end-to-end data analysis on an e-commerce dataset using Microsoft Excel.The goal was to transform raw data into meaningful insights through data cleaning, analysis, and dashboard creation.

📂 Dataset Information:

Dataset was self-created for practice and analysis and it Contains ~1200 records with multiple business-related attributes.

🔑 Key Columns:

OrderID, CustomerName, Age, Gender, City, State, Region, OrderDate, DeliveryDate, Product, Category, Quantity, Price, Discount %, PaymentMethod, Salesperson, Rating, Feedback, ShippingCost, OrderStatus, TotalSales, DeliveryTime, OrderMonth, OrderYear.

⚙️ Tools & Techniques Used:

Microsoft Excel, Data Cleaning, Pivot Tables, Data Visualization (Charts & Dashboard), Basic Excel Formulas.

🔄 Project Workflow:

1️⃣ Raw Data:

Initial dataset containing all customer, product, and order details.

2️⃣ Data Cleaning

Removed duplicate records, Handled missing values, Standardized date formats, Created new calculated columns:Total Sales, Delivery Time (DeliveryDate - OrderDate).

3️⃣ Data Analysis (Pivot Tables)

Analyzed sales by region, product, and time. Created summary tables for business insights.

4️⃣ Dashboard Creation

Built an interactive dashboard using: KPIs (Total Sales, Total Orders, Avg Delivery Days, Avg Rating), Charts (Bar, Line, Pie), Slicers (Region, Product, Year).

📈 Key Insights

Sales are evenly distributed across regions, with South slightly leading and North marginally lower. Tablets are the top-performing product, while headphones show slightly lower sales. Sales in 2024 are slightly lower compared to 2023, with a dip observed mid-year. Payment methods are fairly evenly distributed, though Cash is slightly higher. Rating 4 has the highest number of orders, while ratings 3 and 5 are comparatively lower.

Improved skills in data cleaning and preparation. Gained hands-on experience with pivot tables and dashboard design. Learned how to convert raw data into actionable business insights.
